# 示例对话：增肌期训练后加餐

> 示意对话，展示 mcd-fitmeal 增肌模式 + 预算约束的搭配。营养数据以 MCP 实时返回为准，此处数字为示例。

---

**用户**：我增肌，刚练完，想吃 800 大卡左右、蛋白 50g 以上，预算 45 块。

**Agent**：收到，增肌模式 + 预算 ≤ ¥45。拉数据——

`→ now-time-info`：当前为晚餐时段 ✅
`→ list-nutrition-foods`：已获取官方营养数据
`→ query-meals`：已确认在售
`→ scripts/meal_planner.py --mode 增肌 --cal-min 750 --cal-max 900 --protein-min 50 --budget-max 45`

训练后这套最合适：

## 💪 双层深海鳕鱼堡 + 麦乐鸡（5块）+ 纯牛奶

| 指标 | 数值 | 目标 |
|------|------|------|
| 热量 | 830 kcal | ≈ 800 ✅ |
| 蛋白质 | 52g | ≥ 50g ✅ |
| 脂肪 / 碳水 | 40g / 69g | — |
| 参考价 | ¥45.0 | ≤ ¥45 ✅ |

**为什么是这套**：训练后需要快速补充蛋白 + 适量碳水回糖原。鳕鱼堡 + 麦乐鸡提供 34g 优质蛋白，纯牛奶再补 8g 并帮助补水；碳水 69g 正好覆盖练后窗口。脂肪 40g 略高，但增肌期可接受。

**用户**：脂肪能不能再低点？

**Agent**：可以，把麦乐鸡（5块）换成**麦香鸡（去酱版）单点**如何？——那热量会掉到 700 以下，不达标。或者保持这套、把纯牛奶换成无糖可乐：热量 685 kcal / 蛋白 44g，蛋白就不够 50g 了。我的建议：**保持原方案**，增肌期这点脂肪不是问题。

**用户**：好吧，下单。

**Agent**：`→ calculate-price`：叠加券后应付 **¥38.5**（比预算还省了 ¥6.5 🎉）。确认吗？

**用户**：确认。

**Agent**：`→ create-order`：下单成功！支付链接：…… 练后 30 分钟内吃完效果最好，冲！💪
