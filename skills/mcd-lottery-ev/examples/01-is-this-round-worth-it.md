# 示例 1：这期抽奖值不值得抽？

> 场景：用户看到积分抽奖活动，上头前先问精算师。

**用户**：这期积分抽奖值不值得抽？

**Skill**：我先查一下本期活动信息。

```tool: now-time-info
→ {"datetime": "2026-10-10 16:05:00", "date": "2026-10-10"}
```

```tool: query-lottery-info
→ {
    "activity": "金秋积分抽奖",
    "status": "进行中",
    "prizes": [
      {"name": "巨无霸兑换券", "probability": 0.01},
      {"name": "中薯兑换券",   "probability": 0.04},
      {"name": "50 积分",      "probability": 0.10},
      {"name": "谢谢参与",     "probability": 0.85}
    ],
    "cost_per_draw": 100,
    "free_draws_left": 2,
    "points_balance": 1250
  }
```

奖品价值我按公开口径估算：巨无霸券 ¥25（官方售价）、中薯券 ¥12（官方售价）、50 积分 ¥0.50（按 100 积分=1 元折算）、谢谢参与 ¥0。脚本算出来了：

```
单抽期望回报: 0.78 元
单抽成本:     100 积分 ≈ 1.00 元
EV 比率:      0.78
```

**结论：🟡 可抽**——期望小亏 22%，就当买个开心。

建议：
1. 先把 2 次免费次数抽完（免费的 EV 永远 ≥ 0，不抽白不抽）；
2. 积分抽最多再来 3 次，见好就收——按 EV 算，抽 5 次期望亏 1.1 元，亏得起再玩；
3. EV < 0.7 我就直接劝退了，这期 0.78 属于"能玩但别上头"区间。

要我帮你把 2 次免费次数抽了吗？（需要你明确说"抽"，我才会调用抽奖接口。）

---

**用户**：行，先把免费的抽了。

**Skill**：好嘞，2 次免费抽奖，走你。

```tool: draw-lottery
→ {"result": "谢谢参与", "value": 0}
→ {"result": "50 积分", "value": 0.5}
```

结果：一次谢谢参与，一次 50 积分回血。免费次数用完，收手！剩下的 1250 积分留着换吃的更香 🍔
