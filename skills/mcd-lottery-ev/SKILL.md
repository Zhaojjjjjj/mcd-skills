# mcd-lottery-ev · 麦麦抽奖精算

> 抽奖可以上头，精算师不能。—— 本 Skill 的座右铭

## 何时使用

- 用户询问某期积分抽奖是否值得参与、划不划算（"这期值不值得抽"）
- 用户想知道免费次数用不用、积分抽几次合适
- 用户想复盘历史抽奖战绩（"我上个月抽奖是赚是亏"）

## EV 计算方法（透明口径，可复现）

所有计算由 `scripts/ev.py`（仅 Python 标准库）完成，公式如下：

```
单抽期望回报 E = Σ(奖品 i 的概率 × 奖品 i 的估算价值)
单抽成本 C     = 单抽消耗积分 × 积分单价（默认 100 积分 = 1 元，可配置）
EV 比率        = E / C
历史回本率     = Σ(历史奖品估算价值) / Σ(历史消耗积分 × 积分单价)
```

**奖品价值估算口径**（必须在输出中向用户明示）：

| 奖品类型 | 估算口径 |
|---|---|
| 餐品 / 实物 | 按麦当劳官方售价（元） |
| 优惠券 | 券面额 × 历史核销率（默认 0.5，可配置） |
| 积分奖品 | 按积分单价直接折算 |
| "谢谢参与" / 未中奖 | 价值为 0 |

概率以 `query-lottery-info` 返回的官方公布概率为准；若概率总和不为 1，脚本会自动归一化并明确提示。

## 工作流

1. **确认时间**：`now-time-info` 获取当前时间，确认活动在有效期内。
2. **拉取活动信息**：`query-lottery-info` 获取活动状态、奖品列表、单抽消耗规则、用户可用资源（免费次数、积分余额）。
3. **计算 EV**：整理奖品概率与估算价值，调用 `scripts/ev.py` 计算单抽期望回报、EV 比率。
4. **给出分级建议**（见下）。
5. **代抽（可选）**：仅在用户明确授权后调用 `draw-lottery`；每次代抽前重申消耗，抽完即停，不主动加抽。
6. **战绩复盘**：`query-my-prizes` 拉取历史中奖记录（分页取全），`query-my-account` 确认积分变动，用 `scripts/ev.py --history` 计算真实回本率。

## 建议分级（阈值明确）

| EV 比率 | 评级 | 含义 |
|---|---|---|
| ≥ 1.0 | 🟢 强烈推荐 | 数学期望为正，长期抽稳赚不赔（方差自负） |
| 0.7 – 1.0 | 🟡 可抽 | 小额娱乐消费，期望小亏，就当买个开心 |
| < 0.7 | 🔴 不建议 | 期望亏损超 30%，积分留着换吃的更香 |

**免费次数规则**：免费抽奖的 EV 永远 ≥ 0，有免费次数先建议抽完，再讨论积分抽几次。

## 注意事项

- **抽奖有风险**：EV 是长期数学期望，不保证单次结果；小概率事件的方差极大，请勿上头梭哈。
- **代抽需明确授权**：`draw-lottery` 是真实消耗积分的动作，必须在用户明确说"抽"、"帮我抽 N 次"后才可调用，禁止自行决定抽奖。
- **EV 仅供参考**：奖品估算价值含主观假设（如核销率），结论供决策参考，不构成任何收益承诺。
- **不编造数据**：奖品概率、消耗规则必须来自 MCP 实际返回；MCP 未返回的字段不得脑补，如实告知用户。
- **合规**：仅使用麦当劳 MCP 官方公开能力，遵守麦当劳中国《使用条款》及 MCP 服务规则；本 Skill 为 M-CODE 大赛参赛作品，非官方产品。
