# 示例 2：复盘我上个月抽奖战绩

> 场景：用户抽了一个月，想知道自己到底是赚是亏。

**用户**：复盘下我上个月抽奖战绩，到底亏了多少？

**Skill**：好，我拉一下你的中奖记录和积分账户。

```tool: query-my-prizes (分页取全)
→ [
    {"name": "中薯兑换券", "won_at": "2026-09-12"},
    {"name": "50 积分",    "won_at": "2026-09-15"},
    {"name": "50 积分",    "won_at": "2026-09-21"},
    {"name": "50 积分",    "won_at": "2026-09-28"}
  ]
```

```tool: query-my-account
→ {"points_spent_on_lottery_sep": 2000, "available_points": 1250}
```

奖品按同一口径估值（中薯券 ¥12、50 积分 ¥0.5），脚本复盘结果：

```
累计获得价值: 13.50 元
累计消耗:     2000 积分 ≈ 20.00 元
真实回本率:   67.5% —— 血亏 🩸
```

**复盘结论**：

- 9 月你一共抽了 20 次，中奖 4 次，中奖率看着还行，但中的都是小奖；
- 2000 积分（≈20 元）只换回 13.5 元价值，**净亏 6.5 元**；
- 按当期 EV=0.78 算，你的实际回本率 67.5% 还跑输了期望值——运气站在数学那边，不站在你这边。

**精算师建议**：
1. 以后抽奖前先问我算 EV，EV < 0.7 的局直接不参与；
2. 给自己定个规矩：每月抽奖消耗不超过 500 积分，超了就收手；
3. 好消息：你还剩 1250 积分，够换 2 张巨无霸券了——落袋为安，不比抽奖香？🍔
