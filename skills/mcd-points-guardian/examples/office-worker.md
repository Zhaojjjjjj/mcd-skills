# 示例 1：上班族的 8000 积分

**背景**：小赵，上海上班族，午餐常吃麦当劳，攒了 8000 积分从来没管过。听说积分会过期，来问问。

---

👤 **用户**：帮我查下我的麦当劳积分，听说会过期？

🤖 **麦麦积分守卫**：好嘞，我看一下。
> 🔧 MCP 调用：`now-time-info` + `query-my-account`

🤖：查到了——

- 可用积分：**8000**，冻结 0
- 其中 **3000 积分 7 天后过期**（🟠偏高风险），另有 1500 积分 30 天后过期
- 7 天后过期的这 3000，按商城价约等于 **¥30**，过期就没了

我拉了下商城，用脚本给你算了最值的换法：
> 🔧 MCP 调用：`mall-points-products` → `scripts/expiry_advisor.py`

**方案一（最推荐）**：麦辣鸡腿堡单人餐券 ×2
花 5000 积分，约值 ¥50，每千积分价值 ¥10.0，一次性救下全部 7 天后到期的积分。

**方案二**：巨无霸单人餐券 ×1 + 10 块麦乐鸡券 ×1
花 4600 积分，约值 ¥43，组合更灵活，两顿饭有着落。

要执行方案一吗？

👤 **用户**：换吧，方案一

🤖 **麦麦积分守卫**：收到。二次确认一下：方案一，麦辣鸡腿堡单人餐券 ×2，共 5000 积分（≥5000 按规则需要你再点头一次），确认吗？
> 🔧 MCP 调用：`mall-create-order`（用户确认后）

👤 **用户**：确认

🤖：✅ 兑换成功！订单号 `MCD20261010xxxx`，2 张券已到账（有效期 30 天）。
> 🔧 MCP 调用：`query-my-coupons` 确认到账

另外顺手帮你一键领了 3 张麦麦省的可领券：
> 🔧 MCP 调用：`auto-bind-coupons`

剩下 1500 积分 30 天后过期，不着急，下个月我再提醒你。
