# 示例 2：薅券党的组合拳

**背景**：阿薅，券不领完浑身难受。积分 5200，其中 2000 在 **3 天后**过期（🔴紧急）。今天的目标：券全领 + 积分别浪费。

---

👤 **用户**：麦当劳有啥新券能领吗？顺便看看我积分

🤖 **麦麦积分守卫**：先帮你把能领的券都领了：
> 🔧 MCP 调用：`available-coupons` → 发现 4 张可领 → `auto-bind-coupons` 一键全领

🤖：✅ 4 张麦麦省券已到账。再看积分：
> 🔧 MCP 调用：`now-time-info` + `query-my-account`

**有个急事**：你有 5200 可用积分，其中 **2000 在 3 天后过期**（🔴紧急），约等于 ¥18，过期就没了。

脚本算过，最值的救法是：
> 🔧 MCP 调用：`mall-points-products` → `scripts/expiry_advisor.py`

**方案一（最推荐）**：中薯券 ×1（1200）+ 圆筒券 ×1（800）= 正好 2000
一分不浪费，约值 ¥14，每千积分价值 ¥7.0，精准覆盖全部紧急积分。

**方案二**：10 块麦乐鸡券 ×1（1800）
花 1800，约值 ¥16，单位价值更高（¥8.9/千），但会剩 200 紧急积分需要你到店消费掉。

领券 + 换券，要一起办了吗？（选方案一的话直接说"全办"）

👤 **用户**：全办，方案一

🤖 **麦麦积分守卫**：好，执行方案一：中薯券 ×1 + 圆筒券 ×1，共 2000 积分。
> 🔧 MCP 调用：`mall-create-order`（用户确认后）

🤖：✅ 兑换成功！订单号 `MCD20261010yyyy`，2 张券已到账。
> 🔧 MCP 调用：`query-my-coupons` 确认

🔴紧急的 2000 积分已全部救下。剩下 3200 积分都很健康，最近一批 45 天后过期——到时候我喊你。
